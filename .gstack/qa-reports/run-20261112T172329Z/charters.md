# 五条核心流程检查范围

对象：本项目 `index.html`，以独立的 `http://127.0.0.1:4179` 来源运行。所有数据均为合成演示数据，页面禁止网络业务请求。只修改本项目的缺陷代码及检查记录，不连接真实支付、账号或授权材料。

依据：`docs/designs/commercial-cross-app-flows.md` F01–F05 / PF-01–PF-15。浏览器探索预算 900 秒，修复和定向复查沿用原始证据并如实记录未覆盖项。项目没有 Git 仓库或现有测试框架，不安装依赖、生成 CI 或提交代码。

| 流程 | 入口与演示对象 | 检查契约与主要风险 | 完成依据 |
|---|---|---|---|
| F01 支付与履约 | 工作台、订单；MO261113001/003/004/006/007 | 支付与履约分开；未知查原单；重试不重复补发；迟付与额外付款归属清楚 | 原订单、权益及作者对照一致；重复提交与权限变化无伪成功 |
| F02 AI 费用争议 | 费用账单、AI3001–AI3005 | 保留原扣费；更正与补偿分开；BYOK 不转官方扣费；未知与封顶准确 | 调整与原动作关联且唯一；未决费用持续处理中 |
| F03 退款 | RF4001–RF4006 | 未知查询原退款；失败重新预留；资金已退仅恢复权益；D05 未裁决阻止执行 | 资金与权益状态独立、账户来源账务一致、重复操作不重退 |
| F04 帖子审核 | RV5001/003/004/006 | 候选与公开版隔离；撤回、重提、并发、权限变化使旧审批失效 | 仅有效候选公开，拒绝旧审批且保留历史理由 |
| F05 工单与材料 | TK6001–TK6006 | 对外与内部隔离；撤销/过期/职责变化重验材料；未决业务不能解决 | 作者可继续反馈；输入可恢复；分派不扩大权限 |

共用检查：返回列表恢复上下文、刷新恢复业务与草稿、弹窗关闭/键盘焦点、1024px 和宽桌面、角色边界、存储异常。真实渠道幂等、服务端并发/事务/身份归属不属于本地原型能够证明的范围。
