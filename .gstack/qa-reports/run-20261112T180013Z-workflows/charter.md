# 修改后工作台与工单流程检查

目标：当前 index.html 的工作台与工单处理。范围为浏览器交互与现有恢复回归，不增加依赖或修改真实业务。采用独立本机随机端口、独立标签页和合成演示记录。

1. 工作台：前六项、完整队列、分页、分类、仅我负责、排序、刷新恢复与返回上下文；期望所有职责内待办均可到达。
2. 工单：队列进入、业务摘要、关联详情和返回；期望保留原工单、筛选、滚动与未发草稿。
3. 回复：对外与内部切换、刷新、空白拒绝、各自发送、作者对照；期望内部信息不进入对外回复，仅清已发受众草稿。
4. 状态与权限：受理、交接、未解决业务保护、职责限制、材料有效授权和撤销后阻断。
5. 基本可用性：当前桌面工作台与工单截图、关键控件键盘路径、控制台错误；不宣称全主题全尺寸验收。

完成条件：逐项记录通过、缺陷与未覆盖分支；发现缺陷后复现、最小修复并复查原路径和相邻正常路径。现有 tests/recovery.regression-1.test.py 为恢复基线。
